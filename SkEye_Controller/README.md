# SkEye Controller PCB

KiCad source files for the SkEye physical I/O controller, built around a socketed Raspberry Pi Pico / Pico H. The board provides buttons, status LEDs, and a 3.3 V UART development header. Camera and projector connections are handled by the host computer.

This is a preliminary hardware design. Native KiCad ERC/DRC and hardware testing have not been completed.
