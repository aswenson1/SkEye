# SkEye
*** Pronounced "Sky" ***

CEN4907C Design Project (Formerly known as The Citadel)

Members: Sami Al-jamal, Anna Hudson, Timothy Macias, Anders Swenson

Pitch Link: https://youtu.be/Z7oEOcuJgw8

The Citadel is a tabletop interactive mapping system that uses AR/XR technology to track physical objects placed on a surface and dynamically projects or displays information around them, turning a table into a programmable spatial interface.

# Software Setup

To set up the software environment for running our code, follow the following steps:
- navigate to the software/ directory
- run `chmod +x ./setup.sh`
- run `./setup.sh`
  - this will create the .venv/ directory from the dependencies in  `requirements.txt `
- run `source ./venv/bin/activate`
