# Software

The repository reserves `software/` for the host application and device software,
but no implementation is committed on the current branch.

When software development begins, document:

- supported operating systems and hardware requirements;
- environment and dependency setup;
- camera calibration and marker-generation workflows;
- configuration files and environment variables;
- the host-to-controller communication protocol;
- testing, packaging, and release procedures.

## API reference

API pages can be generated from Python docstrings with `mkdocstrings` once the
package structure is defined.
